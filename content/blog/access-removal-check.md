# Remove access when an assignment ends

A practical access removal check guide for outsourced employment teams.

## Why this control matters

The access removal check record needs a source, owner, and close condition before work moves.

## What to check first

Compare the record with the client scope and label any missing field instead of guessing.

## Handle the exceptions

Route each exception to the accountable owner with a dated next action and reason.

## Review the evidence

Sample one routine item, one exception, and one corrected item each week.
